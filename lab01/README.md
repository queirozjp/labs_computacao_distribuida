# Sistema de Cadastro de Produtos - Laboratório 1 CD (C)

Programa em C para cadastro de produtos com:

* Adição, listagem, busca, atualização e remoção
* Uso de alocação dinâmica (`malloc`, `realloc`, `free`)

---

## Como Compilar

Compile todos os arquivos `.c` juntos:

```bash
gcc main.c produto.c -o main
```

## Como Executar

### Windows:

```bash
.\main
```

### Linux/macOS:

```bash
./main
```
